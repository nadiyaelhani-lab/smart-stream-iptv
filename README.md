Smart Stream IPTV

Application web de télévision en direct développée avec JavaScript Vanilla ES6+ et Tailwind CSS.

Objectif

Développer une interface IPTV responsive permettant de consulter, rechercher et sélectionner des chaînes TV.

Technologies

HTML5

Tailwind CSS

JavaScript ES6+

MockAPI

Fetch API

Git et GitHub

Jira Scrum

Fonctionnalités

Catalogue de 10 chaînes TV

Affichage des chaînes par catégorie

Recherche par nom et numéro

Prévisualisation de la chaîne sélectionnée

Chargement des données avec Fetch API

Gestion des erreurs HTTP

Interface responsive

Architecture

index.html : Structure de l'interface

data/data.json : Données initiales des chaînes

js/main.js : Initialisation de l'application

js/services/api.js : Communication avec MockAPI

js/ui/channels.js : Affichage des chaînes

js/ui/preview.js : Prévisualisation

Installation

Cloner le dépôt GitHub.

Ouvrir le projet dans VS Code.

Lancer index.html avec Live Server.

Vérifier que la connexion Internet est active.

Organisation Git

main : Version stable

develop : Branche d'intégration

feature/* : Développement des fonctionnalités

Gestion du projet

Projet individuel organisé sur Jira avec Scrum, sur un Sprint de cinq jours
